# Evidence

Store reviewed physical-device test evidence here. Use folders by evidence type, such as `metrics/`, and filenames containing role, machine label and timestamp.

Every reviewed result should identify the exact artifact hash, app version, OS and test date. Never store PINs, passwords, tokens, typed text, screen captures or private user content. Summarize the result in `../STATE.json` and add one line to `../WORKLOG.md`; do not duplicate raw measurements in documentation.
